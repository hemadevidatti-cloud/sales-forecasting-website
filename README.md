# SalesCast — Sales Forecasting Website

## About the Project
SalesCast is a web-based sales forecasting application designed to analyze historical sales data and generate future sales predictions.

## Features
- Historical sales analysis
- Time-series analysis
- Sales forecasting
- Forecast overview and visualizations
- Forecast settings and model performance information

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## How to Run Locally
1. Download or clone this repository.
2. Install the required packages:

   `pip install -r requirements.txt`

3. Start the application:

   `python app.py`

4. Open `http://127.0.0.1:5000` in your browser.
